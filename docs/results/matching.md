# 300 位假用戶配對驗證

2026-10-19；純合成資料、既定類別 + 經助理逐筆修正的本機 Qwen 屬性快取，再用現有核心計算向量與配對。

屬性共 107 筆，修正新版模型 46 筆／70 欄；真人確認 107 筆。這是修正後快取的配對測試，不代表原始 Qwen 準確率。逐筆對照見 [synthetic-cache-review.md](synthetic-cache-review.md)。

這次驗證涵蓋核心公式與向量重算；seed 的解析、既定合成分類答案重播、快取、背景工作與 profile 重算另由合成資料整合測試驗證，並測試 demo 配對隔離；不代表真實分類模型或 Qwen 即時推論的準確率。

2026-10-19 相對 main 5c30459，只調整擴充名單中的 6 位連假旅人（06–11）：加入探索不同店家、自炊、甜飲與不同外食預算；原 40 人與其餘 254 人的消費紀錄不變。清單差異來自人物向量改變，107 筆屬性快取、類別規則、相反類型對照、配對門檻與 entries／pick 排序都不變。這批合成習慣是為補齊示範清單而設計，不能當成獨立的配對品質測試。

相反類型在執行前固定於 `configs/persona-opposites.json`：省錢／咖啡、忙碌／家庭、手搖／健身、旅人／貓奴。這是待驗證的假設，不保證一定互補。

門檻與名額直接交給後端 entries／pick，使用 configs/traits.json 的 match 設定：整數百分比 ≥ +30% 為相近、≤ −10% 為互補，各取前 5；同分依顯示名稱字元碼、再依 user_id 排序，本次不篩距離。P@5 分母固定是每人 5 格，名單不足仍算未命中；用戶命中率是至少命中一人。互相命中要求同類型兩人都把彼此列在相近前 5。
