# 25%配方validation下降原因分析（2026-10-16）

分析基準811ebfe；本輪不訓練、不調參、不執行模型推論。只核對已保存的validation預測、訓練報告、train類別計數及CV彙總。原test未開啟或評分。分析待Claude審核。

## 結論

「25%較穩定」限定在先前5折配方比較：平均89.58%，折間樣本SD1.26pp；66.3%組平均87.04%，SD3.05pp。它不保證每一次重訓、每一個類別、某個固定50筆validation都勝出。實際上25%組只在5折中的4折高於66.3%組，第5折90.14%低於91.55%。

本次96%→94%是相同50筆validation淨少答對1筆，且不是只改比例的控制實驗。不能將差異全部歸因於減少假資料，也不能據此否定先前CV結果。

## 已確認的成對變化

46筆兩版皆對、1筆兩版皆錯、1筆由錯變對、2筆由對變錯。每一筆占2個百分點，兩個百分點不足以單獨建立穩定退步的結論。運動／住宿沒有validation樣本；小類不能由少量答對推論穩定。

## 比例以外的差異

| 設定 | 舊版96% | 新版94% |
|---|---|---|
| 訓練起點 | 已微調分類模型續訓，沿用head | 相同CV的公開encoder，重新初始化head |
| 學習率 | 1e-5 | 2e-5 |
| 種子／選擇 | 跑42、43、44，依validation loss選44 | 預先固定42，單一種子 |
| 真實／合成筆數 | 305／600 | 305／102 |
| 保存epoch | 續訓第1輪 | 新訓練第5輪 |
| validation loss | 0.2173331 | 0.2614684 |

舊版3個種子的已選checkpoint accuracy為94%、94%、96%；42與43都保留epoch0。舊96%是這批validation挑選過的候選，新94%是預先固定的單一候選，選擇機會不同。這提供可能的選擇偏差／種子影響，不能量化為下降的唯一原因。

CV三組彼此有控制公開起點、學習率、折內種子；但CV的66.3%組不等同於後來拿來比較的舊96%續訓模型。因此CV配方比較與此次版本比較回答不同問題。

## 生鮮食材的可能機制與反證

真實生鮮訓練17筆未變，合成由60減為10，該類訓練總數77→27；占全train比例8.51%→6.63%。相對地正餐占比18.34%→28.75%。降低每類均衡的合成資料會改變類別平衡及樣本覆蓋，可能影響少量生鮮樣本的決策邊界；合成子集抽樣、初始化與更新步數也可能有影響。

這仍是假說：CV中25%組生鮮F1是68.29%，反而高於66.3%組55.56%。不能因本次3筆生鮮全錯就推論「生鮮一定需要更多假資料」。本輪沒有讀取名稱來判斷語義、格式或標註歧義，沒有證據宣稱具體品名或標註有錯。

## 過擬合與實作問題

新版epoch5後train loss繼續下降（.2363→.1349→.0726），validation loss上升（.2615→.3690→.3331），有後段過擬合跡象；但實際保存的是epoch5，並非第7輪。這不能單獨解釋它比舊版少答對1筆。

既有執行證據顯示v1/v2/v3權重完全相同，FP32重載精度修正未改變分類；本輪從已保存機率重算validation cross-entropy，舊.21733346／新.26146841，與訓練報告相符（CPU/GPU浮點微差）。無證據將下降歸因於保存／重載錯誤。

## 建議與本輪邊界

維持25%為CV優先候選，不因這50筆中淨1筆差異來回改比例。若要追查因果，預先固定公開起點、lr、資料切分及多個共同seed，成對重複25%與66.3%比較，報告平均與離散程度；另將固定更新步數作控制，區分合成比例與計算量效應。不要只挑最好seed，也不要以既有validation反覆試到高分。優先補充生鮮等稀少類別的真實標註，另準備來源獨立的評估資料。

本輪只分析，未執行上述新實驗、未修改資料或模型、未使用GPU。原test繼續封存。
