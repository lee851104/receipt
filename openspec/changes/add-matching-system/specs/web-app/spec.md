# Spec Delta

## Purpose

提供 v2 網頁，讓使用者從登入、上傳發票、看消費月報，一路走到配對和計算過程。這也是結案錄影要操作的畫面。

## ADDED Requirements

### Requirement: 登入與註冊畫面
網頁 SHALL 提供註冊和登入畫面。沒有登入、或任何 API 回應 401 時，網頁 SHALL 導向登入畫面。demo 模式開啟時，登入畫面 SHALL 多一個選單，列出假用戶名單，可以直接切換成其中一位。

#### Scenario: 未登入
- **WHEN** 還沒登入的人打開配對頁
- **THEN** 網頁顯示登入畫面

#### Scenario: demo 切換
- **WHEN** demo 模式開啟，錄影者從選單選一位假用戶
- **THEN** 網頁切換成那位使用者，顯示這位使用者的月報和配對

### Requirement: 上傳與進度
網頁 SHALL 讓使用者選擇 CSV 上傳，並在處理期間持續顯示進度，直到完成或失敗。上傳被拒絕或處理失敗時，網頁 SHALL 把錯誤代碼轉成中文，並附上系統給的說明。

#### Scenario: 上傳完成
- **WHEN** 使用者上傳一份 CSV，背景處理完成
- **THEN** 網頁從顯示進度變成顯示完成，並提供前往「我的月報」的入口

#### Scenario: 上傳失敗
- **WHEN** 上傳的 CSV 有兩個月份
- **THEN** 網頁顯示「一份檔案只能有一個月」這類系統訊息

### Requirement: 不提供獨立品名分類畫面
依 2026-10-16 使用者決定，v2 網頁 MUST NOT 提供品名分類入口、表單或結果畫面。發票上傳的後端分類仍維持原契約。

#### Scenario: 舊分類網址
- **WHEN** 已登入使用者打開舊的 #classify 網址
- **THEN** 回到我的月報首頁，不出現分類輸入或分類 API 請求

### Requirement: 月報與配對
網頁 SHALL 用 API 取得的資料，顯示現有的月報、品味關係圖、相近和互補清單以及距離篩選。

#### Scenario: 切換距離
- **WHEN** 使用者在配對頁把範圍從「不限」改成「同一區」
- **THEN** 清單依 API 回傳的結果更新

### Requirement: 首頁與設定導覽
登入後未指定有效功能網址時，網頁 SHALL 以「我的月報」為首頁。主導覽 SHALL 只提供「我的月報」與「找到同好」；右上角「設定」收納上傳檔案、帳號設定及切換帳號。有效功能網址 SHALL 可重新整理並保留目前功能。

#### Scenario: 登入與初次使用
- **WHEN** 使用者登入或從無功能網址的入口進入
- **THEN** 顯示我的月報；沒有月份時，提示從右上角設定上傳檔案

#### Scenario: 使用設定選單
- **WHEN** 使用者打開右上角設定並選擇上傳檔案或帳號設定
- **THEN** 顯示該功能並收起選單；Escape、點擊外部或鍵盤焦點離開也會收起選單

### Requirement: 整屏分頁瀏覽
首頁 SHALL 直接顯示月報，MUST NOT 再顯示獨立的我的品味頁或要求另開完整報表視窗。月報 SHALL 依序提供品項概覽、消費節奏、文字雲、日期分布、月份比較五個章節，固定月份與章節導覽。整屏一般滾輪手勢 SHALL 翻到相鄰一頁；觸控與超高內容 SHALL 保留原生捲動，不能裁切資料。各章 SHALL 以可用報告視窗調整圖表比例，節奏解讀、文字雲計數說明及完整月份比較 SHALL 可自行展開，不讓預設頁面被長篇說明撐高。

#### Scenario: 第一屏品項圖表
- **WHEN** 已登入且有月份資料的使用者打開首頁
- **THEN** 顯示所選月份金額、去重發票數、紀錄日數、類別金額與占比；點類別可查看同類品項金額排行
- **AND** 同類同名品項合併加總，預設前六項且揭露其餘項數與金額，可展開全部；原始明細預設收合

#### Scenario: 章節式轉場
- **WHEN** 使用者以一般滾輪或固定章節按鈕切換頁面
- **THEN** 以緩入緩出轉場切換，固定導覽標示目前章節；新章節請求可中斷前次轉場，鍵盤 PageUp／PageDown／Home／End 可切換能完整容納的頁面
- **AND** 減少動態效果時立即切換；超高頁面保留原生捲動與完整可讀性

#### Scenario: 動態文字雲
- **WHEN** 使用者查看文字雲章節
- **THEN** 以原有深色與類別配色呈現出現次數，點選文字可查日期與金額；文字以避免碰撞的自然散佈呈現，藉由大小、角度、明暗與不同步漂浮表現前後層次，保留原始次數讀值與柔光，提供播放／暫停
- **AND** 首次尊重減少動態偏好；離開可視區時暫停整區動畫；滑鼠停留或鍵盤聚焦某個詞時只暫停該詞，其他文字與柔光繼續運行

#### Scenario: 更新與清理月報
- **WHEN** 切換月份、資料重算或身分失效
- **THEN** 月份切換同步更新所有月報圖表；重算或身分失效清除原報表 iframe，避免殘留舊資料；沒有月份時顯示上傳提示

### Requirement: 計算過程面板
使用者點選配對清單中的一個人時，網頁 SHALL 先顯示品味關係圖，計算過程預設收合；只有點開「查看計算過程」才渲染計算明細：每一格的「我的值 × 對方的值 × 權重 = 乘積」、內積、分母（雙方加權長度相乘 + 0.25）、各格貢獻，以及最終分數，並用同一份資料畫出兩人的品味關係圖。面板上的百分比 MUST 與清單卡片上的相同。

#### Scenario: 打開面板
- **WHEN** 使用者點選相近清單第一名，再展開「查看計算過程」
- **THEN** 面板逐格列出計算，最後的百分比和那張卡片上的一樣

#### Scenario: 專注配對結果
- **WHEN** 使用者點選配對對象
- **THEN** 隱藏配對列表與篩選，切到獨立結果畫面；最新有效資料顯示連線圖與綜合解讀，分數只在圖中央呈現，圖例與計算明細預設收合
- **AND** 桌面一般尺寸一屏呈現圖與解讀，窄螢幕及展開細節只由外層結果區捲動，內嵌圖頁不得再有獨立捲軸
- **AND** 過期或失敗回應，以及已離開配對頁的回應，不得拉動畫面；失敗顯示訊息並保留返回入口

#### Scenario: 返回配對列表
- **WHEN** 使用者按下「返回配對列表」
- **THEN** 取消尚未完成的解讀查詢並清除結果，恢復原列表、篩選與捲動位置，鍵盤焦點回到所選對象
- **AND** 返回後才到達的回應不得重新開啟結果

#### Scenario: 保持配對清單簡潔
- **WHEN** 使用者只查看配對清單，或選擇新的對象／切換篩選
- **THEN** 不自動展開計算明細；清單不預先呼叫 explain，選擇對象後才取得關係圖與明細共用的 explain 資料

### Requirement: 帳號設定頁
網頁 SHALL 提供帳號設定頁，可以修改顯示名稱、修改密碼、列出已上傳的月份並逐月刪除、刪除帳號，以及登出。刪除月份和刪除帳號前 SHALL 先跳出確認；刪除帳號時還要再輸入一次密碼。假用戶的設定頁 SHALL 顯示為唯讀。

#### Scenario: 刪除月份
- **WHEN** 使用者在設定頁按下 8 月的刪除，並在確認視窗按確定
- **THEN** 月份清單不再有 8 月，「我的月報」也依剩下的月份更新

#### Scenario: 刪除帳號
- **WHEN** 使用者按下刪除帳號，輸入正確密碼並確認
- **THEN** 網頁回到登入畫面，舊帳號已無法登入

#### Scenario: 登出
- **WHEN** 使用者按下登出
- **THEN** 網頁回到登入畫面，按瀏覽器的上一頁也看不到需要登入的資料

#### Scenario: 假用戶的設定頁
- **WHEN** 錄影者以假用戶身分打開設定頁
- **THEN** 頁面上的修改和刪除按鈕都無法使用，登出仍然可以使用

### Requirement: v1 線上版和原始檔不變
GitHub Pages 上的 v1（根目錄的 `invoice-insights.html`）MUST 維持現在的內容；v2 網頁 SHALL 放在 `src/web_v2/`，由同一個本機服務在 `/web/` 底下提供，不覆蓋 v1。`src/web/` 是 v1 報告的建置來源，MUST NOT 被提供，也不為 v2 修改；v2 需要的頁面和 JS 從 `src/web/` 複製到 `src/web_v2/`。

#### Scenario: 建置 v2
- **WHEN** 建置或啟動 v2 網頁
- **THEN** 根目錄的 `invoice-insights.html` 和 `src/web/` 底下的檔案都沒有任何變動

#### Scenario: v2 入口
- **WHEN** 服務啟動後打開 `/web/`
- **THEN** 顯示 `src/web_v2/index.html`，也就是 v2 的入口頁

#### Scenario: v1 的原始檔不被提供
- **WHEN** 要求 `/web/` 底下一個只存在於 `src/web/`、還沒有複製進 `src/web_v2/` 的檔案
- **THEN** 系統回應 404
