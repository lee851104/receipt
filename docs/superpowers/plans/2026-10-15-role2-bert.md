# 角色 2：BERT 微調 Implementation Plan

> 依使用者「請繼續微調 BERT」及既有分類 brief 執行，由本聊天使用 executing-plans 與 TDD 完成；保留現有未提交成果。

**Goal:** 本機 RTX 4060 微調 bert-base-chinese 三個種子，驗證可重載、CPU 推論及相同固定測試集上的三模型彙總。
**Architecture:** 新增離線 BertClassifier、train CLI 與一次性比較 CLI；沿用 fixed_split_data 的資料驗證與低樣本計分，下載程序只讀公開權重。A/B 不重訓。所有私人產物放主專案 data/role2。
**Tech Stack:** Python 3.12、PyTorch 2.8.0 CUDA 12.8（獨立 bert-runtime/.venv）、Transformers 4.57.1。
**Spec:** docs/category-models-brief.md；openspec/changes/add-matching-system/specs/model-evaluation/spec.md；角色 2 任務 3.5。

## Constraints and decisions

- 本機原資料不顯示給雲端；CLI 只回傳彙總，第三方文字輸出抑制。HF 模型預先下載，訓練/預測全離線。不改其他角色檔案，不啟停他人服務，不使用 Colab。
- google-bert/bert-base-chinese revision 8f23c25b06e129b6c986331a13d8d025a92cf0ea，下載逐檔驗證上游雜湊。輸入 max_length=32；全參數微調十分類 head。
- 固定 v2 train=643（43 real+600 synthetic）、validation=7、test=7；seed=42/43/44。訓練只讀取 train 供梯度；validation cross entropy 決定最佳 epoch。
- AdamW lr=2e-5、weight_decay=.01、batch=16、max_epochs=10、patience=2、min_delta=1e-4、gradient clipping=1、FP32；不做超參數搜尋。若資源不足保留失敗紀錄，不偷偷改設定。
- 每個種子各自從同一預訓練權重開始；使用 validation loss 最低 checkpoint。選部署候選只用 validation loss；三種子均列結果、平均及母體標準差。
- test 只在三種子全部凍結後由獨立比較程序一次跑完 A/B/C；評分前寫 exclusive 標記防止無意重複評估，不看 test 再改參數。資料既往參與 CV，仍稱開發留出結果，非獨立泛化證據。
- 每類真實樣本 <5 時不計 precision/recall/F1，macro-F1 若全不合格則 null。CPU 1000 筆使用循環 train 名稱，只測成本，不作準確率。
- 保存 safetensors、tokenizer、資料與權重指紋、設定、逐 epoch 彙總、模型重載一致證據；CPU 測速含 tokenizer+encoder+head，模型大小含完整權重。
- 本輪只做微調與比較，不接 API、不公開模型、不 commit/merge。

## Review focus

1. test 不可進入訓練、早停或選模型。
2. 空 validation 不可退回 train 分數挑 checkpoint；非有限 loss 失敗。
3. 重載需核對實際權重與完整機率，不能只核對標籤。
4. 模型輸出不得覆寫來源；中斷不應留下成功報告；指紋改動拒絕。
5. tokenizer 不得隱含下載；公開文件與例外不可包含私人品名。
