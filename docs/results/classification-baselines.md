B 的 LR bundle 為 86,601 bytes，另需 96,405,251 bytes 編碼器；大小不含 Python、套件及小型 manifest。A 不使用編碼器，表內對應時間為 0。兩者各以新程序依序量測，使用 CPU 單計算執行緒，不占用 GPU。

1000 筆為循環重複訓練名稱，暖機後量測完整流程；B 每次重新編碼，沒有向量快取。這不是額外的正確率證據。初次編碼器載入包含套件匯入與檔案完整性檢查；重載時間在套件已匯入的同一程序測量，不能當成冷啟動時間。單次速度受系統負載與名稱長度影響，不能直接和舊 CV 報告的時間比較。
